Problem Statement

The Dual Failure of Current NPCs

1. Traditional Scripted NPCs

  • Predictable, repetitive dialogue trees (A, B, C options).
  • Zero emotional memory of player tone or respect.
  • Static game triggers with zero narrative emergence.

2. Naive LLM Wrappers

  • Hallucinations: LLMs break character or give game keys away for free ("Prompt Injection").
  • Disjointed State: Dialogue does not actually modify world health, quest logs, or inventory.
  • No Lie Detection: Player can falsely say "I fixed it!" and the LLM blindly believes them.
Our Solution

The Golden Architectural Rule

"The LLM only proposes actions; the game engine decides, validates, and enforces."

1. Free-Text Input

Players speak freely via text or voice. No multiple-choice constraints.

2. Structured Proposal

LLM outputs strict JSON: proposed reply, mood change, trust shift, and actions.

3. Server Validator

Deterministic code checks physical world flags and trust gates before applying state.

Core Mechanic

Verifiable World Flags & Lie Detection

How Raghu separates truth from deception:

Player Bluffs (Lie Caught)

Player: "Raghu, I found Lakshmi the cow!"

Server: Checks flags.found_cow === false

Result: Raghu calls out the bluff, Trust drops by -2, mood turns angry.

Player Actually Acts (Truth)

Player: Clicks world button "Search North Field"

Server: Sets flags.found_cow = true

Result: Quest completes, +30 Farm Health, item rewarded!
